Official update channel for AI Rankboard.

Download signed Android releases:
https://github.com/Aigooz/ai-rankboard/releases/latest

Source and documentation:
https://github.com/Aigooz/ai-rankboard

Web app:
https://aigooz.github.io/ai-rankboard/

- app-update.json: Android/iOS update manifest
- app-release.apk: signed release APK

The Android app checks the manifest URL and downloads the APK after SHA-256 verification.
The current Android version is 0.20.19 (code 69), requiring Android 8.0+.
Official update URLs are built in; users do not need to enter an address.
Current leaderboard snapshots are published in the main source repository.
iOS links point to unsigned development builds, not directly installable releases.
Keep APK and manifest updates in one commit and preserve the original signing key.
